# Security policy

## Supported versions

Only the latest version on the `main` branch is currently supported.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. If that feature is unavailable,
contact the repository owner through the linked GitHub profile without publishing exploit details.

Do not open a public issue containing credentials, private customer data, or reproducible exploit
information.

## Data handling

The repository contains synthetic sample data only. Users are responsible for protecting source
files and generated outputs when adapting the cleaner to real customer or financial data.
